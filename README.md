# cry_bug

`pry` like it was before.  Quit yer cryin!  

A fully reassembled Pry toolkit stack.  With VIM keybindings. 

## Usage
* Terminal: Type `cry` or `ry`
* Code Breakpoints: Add `cry` or `ry` directly on any line.
* Press `ESC` inside a console prompt window for full Vim modal navigation controls.
